DATA PIPELINE
------------------------------------------------------------------------
Raw source:  UCI Bank Marketing (Moro, Cortez & Rita, 2014)
             41,188 records, 20 features + binary target
             Portuguese bank phone campaign, May 2008 to Nov 2010

Pre-processing:
  - 'unknown' categorical values converted to 'missing' category
  - Binary indicator flags for default_was_unknown, education_was_unknown
  - pdays=999 recoded with was_contacted_before indicator + median impute
  - Call duration dropped (perfect target leakage per UCI documentation)
  - 23 duplicate rows removed
  - Target yes/no encoded as 1/0
  - Month and day_of_week set as ordered categoricals
  - Dropped cons.price.idx, cons.conf.idx, nr.employed (redundant with euribor3m)
  - One-hot encoding with drop_first=True (19 features -> 52 features)
  - 80/20 stratified train/test split, random_state=42
  - StandardScaler fit on training set only

Training data:
  - Training rows: 32,950 customers
  - Test rows:      8,238 customers
  - Feature count:  52 (after one-hot encoding)
